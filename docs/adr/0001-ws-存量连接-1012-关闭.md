# ADR-0001 — WS 存量连接以 close 1012 关闭（编辑 / 停用 / 删除即生效）

状态：已采纳 ｜ 日期：2026-10-24

## 背景

WS 接口的剧本（onOpen 有序推送 / onMessage 回包策略 / interval 定时推送）在连接建立时执行或订阅。路由被编辑、停用或删除后，存量连接仍挂在旧剧本上运行；客户端没有可靠手段感知"接口配置已变化"。

## 决策

注册表 `change` 时，WS 网关比对每条连接所属路由的签名（`serviceId` / `path` / `auth` / `disabled` / `ws`），签名发生变化的存量连接统一以 close code **1012**（Service Restart）关闭（`src/server/ws-gateway.ts` 的 `WS_CLOSE_ROUTE_CHANGED`）。客户端收到 close 后重连，新握手取新剧本。删除服务时连接立即销毁，`stop()` 带超时兜底，保证端口可立即复用。

## 后果

- 变更即时生效，网关内不需要"连接热更新"机制（不重放 onOpen、不迁移回包游标）。
- 代价：存量连接的运行状态（序列回包进度等）随连接重建；客户端需具备基本的重连逻辑（浏览器 WebSocket 原生触发 `onclose` 后重连即可）。
- 1012 语义（服务重启）与实际场景吻合，客户端可据此与异常断开区分。
