# Web 控制台使用指南

启动 PolyMock 后浏览器打开 <http://localhost:33233>，左侧边栏切换四个视图（选择会记忆）。侧边栏还可一键切换全局场景集（`settings.activeVariant`）、配置管理令牌（`POLYMOCK_ADMIN_TOKEN`，仅保存在本机 localStorage），并显示 WS 连接数。

## 接口管理

服务分组列表（新建/删除/端口或 basePath/运行状态，头部徽标快捷设置代理穿透）与接口卡片（方法色标、条件摘要、变体列表）。

- **卡片**：HTTP 与 WS 卡片同处一个服务分组。WS 卡片为紫色 WS 徽章 + 一行等宽剧本摘要 + 认证 / 停用 / 连接数状态 chip（连接数仅 > 0 时渲染，点击跳转调试台），剧本详情以 `<details>` 折叠。HTTP 与 WS 卡片的内容区（响应体 / 剧本步骤）统一默认折叠，折叠行带单行截断预览；大响应体在展示层截断（编辑抽屉始终加载完整内容，保存不截断）。CRUD 路由按集合分组展示（组头可弹窗查看集合数据、整集合删除）。
- **「新增/编辑接口」抽屉（五段卡片）**：
  - **基本信息**：服务分组、名称、请求方法与路径（支持 `:param` 段）。
  - **请求准入**：把原先挂在默认响应上的条件独立成共享门槛——开关即 `requireMatch`，失败码下拉即 `gateStatus`（400 / 404 隐藏接口 / 422）；默认折叠，折叠态头部徽标显示已开启 / 已关闭。条件行为「来源 / 参数名 / 操作符（存在·等于·非空·正则）/ 值」，类型下拉仅在「等于」时出现，保留启用与必填勾选；Body 支持字段包含（subset）/ 完整 JSON 相等（deepEqual）/ 原文全文相等（textEqual）三种策略。
  - **响应分支**：按 Tab 编辑——默认响应为 fallback、不写条件；分支标签可拖动调整匹配顺序（聚焦后 ← / → 也可移动），删除按钮在分支框体右上角；每个分支含条件编辑器与响应编辑器（状态码、body、格式化）。
  - **高级选项**：自定义响应头（「启用自定义响应头」开关 + 当前行编辑，同名多条按多值头）、认证（API Key / Bearer）、延迟 / 抖动 / 故障率、序列响应、CRUD 开关（开启后可一键创建配套的列表/创建/详情/更新/删除路由）、停用开关（仅编辑态）。
  - **匹配预览**：纯前端本地推演——请求体解析 → 路径 → 认证 → 请求准入 → 序列响应 → 全局场景集 → 分支 → 默认响应，不发送真实请求。请求体语义与后端一致：Body 仅在测试请求头含 `Content-Type: application/json`（或 `*+json`）时按 JSON 解析参与匹配，非法或顶层标量 JSON 按解析器 400 拒绝。
- **「新增/编辑 WS 接口」抽屉（五区块）**：基本（服务 / 名称 / 路径 / 地址预览）、握手与准入（认证方式 + 令牌，令牌只在抽屉配置与显示）、① 连接后推送 onOpen（延迟 + 内容列表 + 循环开关）、② 收到消息时 onMessage（回包策略 echo / fixed / sequence / none + 回包内容）、③ 定时推送 interval（开关 + 间隔 + 内容）；底部含停用开关与 1012 重连提示。
- 支持 OpenAPI 导入抽屉。

## WS 调试台

面向 WS 接口的可视化调试：

- 连接条：目标接口下拉 + 可编辑连接地址（可追加 `?token=` 等查询参数）+ 连接 / 断开
- 实时连接列表：轮询 `/__polymock/ws/connections`，含连接 id、对端地址、收发帧计数
- 发送消息：JSON 自动校验 + 快捷示例
- 帧时间线：↑ 出 / ↓ 入 / ⇄ 系统，可清空

帧只保存在当前页面，不写进 HTTP 请求日志。

## 嵌入测试

输入任意页面地址，将其嵌入可拖拽调整宽高的 iframe 容器中（右/下/右下边缘拖拽、一键铺满、新标签页打开），便于在控制台内直接验证页面与 Mock 的联调效果。

## 请求日志

日志列表与过滤（状态/服务/路径关键字），实时（SSE）/轮询模式徽标，支持重放、复制 curl、清空、把代理条目保存为接口；WS 连接级日志（method = WS，close 时记录连接 id / 收发帧计数 / closeCode）同样展示。
